# Naman Soni — Portfolio

A modern, editorial-style developer portfolio built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

- Update content in `app/components/Portfolio.tsx`.
- Replace the stylized profile visual in the About section with your own image when ready.
- Replace placeholder email/social links in the Contact section.
- Add real project URLs and screenshots to the Projects section.
